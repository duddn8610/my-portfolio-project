# YouTube 트랜스크립트 추출 워크플로우

## 프로젝트 개요
YouTube 동영상에서 자동 생성된 자막이나 업로더가 제공한 자막을 추출하는 간단한 워크플로우입니다. YouTube 동영상 ID만으로 텍스트 형태의 트랜스크립트를 획득할 수 있습니다.

## 주요 기능

### 1. YouTube 자막 추출
- **YouTube Transcript Node**: 전용 노드를 사용한 자막 추출
- **자동 자막**: YouTube 자동 생성 자막 지원
- **수동 자막**: 업로더가 직접 업로드한 자막 지원

### 2. 단순한 입력 방식
- **Video ID 입력**: YouTube URL이나 동영상 ID 입력
- **수동 트리거**: 필요시 즉시 실행 가능

## 기술 스택

### 노드 구성
- **Manual Trigger**: 수동 실행 트리거
- **YouTube Transcript Node**: 전용 트랜스크립트 추출 노드

### 입력 형식
- YouTube 동영상 ID (예: `dQw4w9WgXcQ`)
- YouTube URL (자동으로 ID 추출)

## 워크플로우 구성

### 1. 수동 실행 트리거
```
트리거 타입: Manual Trigger
실행 방식: 'Execute workflow' 버튼 클릭
```

### 2. 트랜스크립트 추출
```
노드: YouTube Transcript Node
입력: {{ $json.query }} (동영상 ID 또는 URL)
출력: 시간대별 텍스트 배열
```

## 사용법

### 1. 동영상 ID 입력
```json
{
  "query": "dQw4w9WgXcQ"
}
```

### 2. 전체 URL 입력
```json
{
  "query": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
}
```

### 3. 실행 및 결과 확인
- 'Execute workflow' 버튼 클릭
- 트랜스크립트 텍스트 결과 확인

## 출력 형식

### 기본 출력 구조

## 제한사항

### 1. YouTube 정책 의존
- YouTube의 자막 제공 정책에 따라 결과 변동
- 일부 영상은 자막이 제공되지 않을 수 있음

### 2. 언어 지원
- 자동 생성 자막의 정확도는 언어별로 차이
- 일부 언어는 지원되지 않을 수 있음

### 3. API 제한
- YouTube의 API 정책 변경에 영향받을 수 있음
- 대량 처리 시 속도 제한 가능
