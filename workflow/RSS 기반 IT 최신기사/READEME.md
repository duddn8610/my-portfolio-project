# RSS 기반 IT 뉴스 자동화 시스템 (Latest_IT_article)

## 프로젝트 개요
IT World RSS 피드를 자동으로 수집하여 AI가 요약한 뉴스를 매일 정해진 시간에 Slack 채널로 전송하는 자동화 시스템입니다. 최신 IT 트렌드를 놓치지 않고 팀원들에게 전달합니다.

## 주요 기능

### 1. 자동 뉴스 수집
- **RSS 소스**: IT World (https://www.itworld.co.kr/feed/)
- **수집 주기**: 매일 오후 9시 자동 실행
- **수집량**: 최대 10개 최신 기사

### 2. AI 기반 뉴스 요약
- **AI 모델**: Google Gemini
- **요약 스타일**: 각 기사를 정확히 3줄로 간결하게 요약
- **형식**: Slack 메시지 최적화된 마크다운 형식

### 3. 자동 Slack 전송
- **채널**: #it기사_소식 (C09B72E6T0B)
- **형식**: 이모지와 함께 구조화된 메시지
- **내용**: 제목, 발행일, 카테고리, 요약, 원문 링크

## 기술 스택

### RSS 처리
- **RSS Feed Read**: 실시간 피드 파싱
- **데이터 제한**: 최신 10개 기사로 제한
- **데이터 집계**: 제목, 링크, 내용, 발행일, 카테고리 구조화

### AI 요약 시스템
- **Google Gemini**: 자연어 처리 및 요약
- **Temperature**: 0.1 (일관된 요약 품질)
- **프롬프트 엔지니어링**: 정확한 3줄 요약을 위한 맞춤형 지시사항

### 자동화 스케줄링
- **Schedule Trigger**: 매일 21시 자동 실행
- **Manual Trigger**: 테스트 및 즉시 실행 지원

## 워크플로우 구성

### 1. 데이터 수집 단계
```javascript
RSS Feed → Limit(10개) → Aggregate(구조화)
```

### 2. 데이터 전처리 (Code 노드)
```javascript
// RSS 데이터를 AI가 이해할 수 있는 형태로 변환
const articles = [];
for (let i = 0; i < articleCount; i++) {
  articles.push({
    제목: aggregatedData.제목[i],
    링크: aggregatedData.링크[i],
    내용: aggregatedData.내용[i],
    발행일: aggregatedData.발행일[i],
    카테고리: aggregatedData.카테고리[i]
  });
}
```

### 3. AI 요약 생성
```

사용자 입력: 구조화된 기사 데이터
출력: Slack 최적화 마크다운 형식
```

## AI 프롬프트 상세

### 시스템 메시지
```
당신은 전문 IT 뉴스 에디터입니다.

핵심 규칙:
- 반드시 사용자가 제공한 실제 RSS 데이터만 사용
- 기사를 임의로 생성하거나 내용을 추가하지 말 것
- 제공된 제목, 링크, 내용을 그대로 활용
- 내용이 부족하더라도 실제 데이터 범위 내에서만 요약
- 정확성이 창의성보다 우선

각 기사를 슬랙 메시지 형식으로 깔끔하게 3줄 요약하고, 지정된 이모지를 정확히 사용하세요.
```

### 사용자 프롬프트
```
아래는 실제 RSS 피드에서 가져온 IT 뉴스 기사들입니다. 각 기사를 정확히 3줄로 요약하여 슬랙 메시지 형식으로 만들어주세요.

중요 지침:
1. 위에 제공된 실제 기사 데이터만 사용하세요
2. 임의로 기사를 생성하거나 변경하지 마세요
3. 각 기사마다 다음 형식을 정확히 따라주세요:

⚙️ [실제 제목]
📅 [실제 발행일] | 🏷️ [실제 카테고리]
[실제 내용 기반 3줄 요약 - 핵심 내용만]
🔗 <[실제 링크]|원문 보기>

4. 각 기사 사이에는 빈 줄 하나로 구분하세요
```
